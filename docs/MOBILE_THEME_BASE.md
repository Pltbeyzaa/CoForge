## Mobil Tema (Goz Yormayan Kirik Beyaz)

Mobil uygulamada web ile tutarli bir gorunum icin asagidaki temel renkleri kullan:

- Background: `#F6F4EF`
- Surface/Card: `#FFFDF9`
- Primary: `#4F46E5`
- Primary Dark: `#4338CA`
- Text: `#1F2937`
- Muted Text: `#64748B`
- Border/Divider: `#DDD6C9`

Ornek Flutter `ColorScheme` eslestirmesi:
- `background` -> `#F6F4EF`
- `surface` -> `#FFFDF9`
- `primary` -> `#4F46E5`
- `onSurface` -> `#1F2937`
- `outline` -> `#DDD6C9`
